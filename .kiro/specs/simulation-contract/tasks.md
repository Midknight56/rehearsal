# Implementation Plan

Eighteen tasks (0 to 17) on branch `kiro/simulation-contract`, November 4–11, inside the 550-credit cap; Kiro does every task, and there is no integrator, no fleet and no second agent; no task depends on a hook firing, because hooks do not fire in Kiro CLI runs and are observed later in the Kiro IDE; tasks 2 and 3 are the two bounded tasks whose credits set the November 11 reallocation. Every task ends with its `Verify:` line passing, a commit carrying `Kiro-Task: simulation-contract/<n>` and a `docs/kiro-log.md` row the same day. Task 0 creates `package.json`, the lockfile, `vite.config.ts`, `src/main.tsx` and `src/app.tsx`; a later task edits `package.json`, the lockfile or `vite.config.ts` only when its own Verify line needs it and names the change in its log row. Nothing in this spec edits `src/ui/`, `src/replay/`, `src/imports/`, `src/storage/`, `src/comparison/`, `src/exports/`, `tests/e2e/`, `tests/comparison/`, `.kiro/specs/scenario-editor-and-replay/`, `.kiro/specs/paired-comparison-and-release/`, or `src/main.tsx` and `src/app.tsx` after task 0; a change to the `Scenario` type after task 0 follows plan section 5 and gets its own log row. Shell lines in Verify use PowerShell syntax (the working machine runs Windows); `npm` and `npx` lines are the same in any shell.
