Rehearsal needs a way to share a plan as a link. A person who has built or edited a plan on the Plan screen presses a button named "Copy share link". The link holds the whole scenario (it is the same scenario the JSON save writes), so nobody has to send a file. When someone opens the link, the app loads that plan on the Plan screen, as if it had been opened from a JSON file, with the usual dialog or message for a plan that has warnings. No server is involved: the link is the app address followed by a hash (#) part that holds the scenario, compressed and encoded in the browser. The status region says "Share link copied" after the copy. If the plan is too big for a link (over 6,000 characters in all), nothing is copied and the status region says "This plan is too large to share as a link. Save it as a JSON file instead." If a link is damaged or holds a scenario the app refuses, the app stays on the landing screen and the status region says why in plain words, and nothing crashes. The link never leaves the browser: opening it makes no request to any other address.
