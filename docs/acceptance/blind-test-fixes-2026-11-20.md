# Blind test fixes, 2026-11-20

Three first-time testers used the live app with no notes: `haiku`, `sonnet-a` and `sonnet-b` (reports in `blind-test/<name>/REPORT.md`, outside this repository). This file lists every problem they reported for Rehearsal, and the faults found while checking them. Kiro did every step in the Kiro CLI on branch `blind-fixes`; nothing was committed or deployed.

Each REPRODUCED row has a browser test in `tests/e2e/blind-test-fixes.spec.ts` (headless Chromium, 360 x 640 and 1,920 x 1,080 unless the row says otherwise). Every one of those tests was run before the fix and failed for the reason given in the row, then passed after it. The component tests in `tests/ui/blind-test-fixes.test.tsx` were written after the fixes as guards for `npm run verify` (which does not run the browser tests); they were not run against the old code.

## Open, not changed

- The floor plan drawing (an SVG that scales with the zoom) draws its labels at 9.3 px and the server numbers in the markers at 8 px at Fit on 1,920 x 1,080. That is under the job's 12 px rule. Larger labels at Fit would overlap the markers and each other, which `design-fixes.spec.ts` 6 checks. No tester reported it. The game view canvas text was not measured by these checks.
- `npm run verify` failed once on `tests/comparison/properties.test.ts` P9 with `Test timed out in 5000ms` (a time limit, not a counterexample). The file passed alone (12 of 12) and the next full verify exited 0. No file under `src/comparison` or `tests/comparison` was changed.

## Checks run

- `npx playwright test tests/e2e/blind-test-fixes.spec.ts`: before the fixes 17 of 22 failed (the 5 NOT REPRODUCED tests passed); after them 24 of 24 passed (BT16 was added after the audit). These tests were corrected after their first run; each correction fixed a fault of the test, not a weaker check: BT1 first failed on a locator that matched both the field message and the status region (BT2 showed the real fault, `Run complete`, on the old code, and BT1 was not rerun on the old code after the locator fix); BT3 to BT6 counted the cells of the header row that is clipped for a screen reader; BT4's line count was measured from the cell's text instead of its box; BT12 looks for the sample sentence above the picture instead of in the first paragraph; BT14 was narrowed to the Compare button, the one the tester named.
- Tests changed because the lead's decisions changed the product: `tests/ui/compare.test.tsx` (the default picks, and the way it makes the picks equal), `tests/e2e/journey.ts` (the keyboard journey accepts a pick that is already pressed), `tests/e2e/design-spacing.spec.ts` (tab order after the tabs is `Print run sheet`, then `Go to the run`).
- `npx playwright test` (all 213 browser tests): 208 passed, 5 skipped, 0 failed.
- `npm run verify`: exit 0 (typecheck clean; `test:model` 303 passed, 1 skipped; `test:ui` 551 passed; build done).
